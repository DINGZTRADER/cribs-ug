# Uganda Property Finder (Frontend)

This is the Next.js frontend for the Uganda Property Finder application, ported from the provided HTML prototype.

## Getting Started

1.  Install dependencies:
    ```bash
    pnpm install
    ```

2.  Run the development server:
    ```bash
    pnpm dev
    ```

3.  Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deploy on Vercel

The easiest way to deploy your Next.js app is to use the [Vercel Platform](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme).

1.  Push this repository to GitHub/GitLab/Bitbucket.
2.  Import the project into Vercel.
3.  **Crucial Step**: In the "Root Directory" setting, select `apps/web-client`.
4.  (Optional) Add Environment Variables if needed.
5.  Click Deploy.

Your application will be live in minutes.
